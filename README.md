# Усадьба «Михайловское»

Учебный адаптивный сайт по макету Figma.

Адрес после включения GitHub Pages: https://lubochkachayka-ai.github.io/mikhailovskoe/

Заявки сохраняются только в текущей вкладке браузера. Письма не отправляются, деньги не списываются, учебные билеты недействительны для посещения.

Для GitHub Pages выберите Settings → Pages → Deploy from a branch → main → / (root).

Обновления файлов ветки main появляются по тому же адресу сайта.
